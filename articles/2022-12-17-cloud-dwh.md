# Redshift

* [Amazon Redshift: Ten years of continuous reinvention - Amazon Science](https://www.amazon.science/latest-news/amazon-redshift-ten-years-of-continuous-reinvention)
* [Amazon Redshift re-invented - Amazon Science](https://www.amazon.science/publications/amazon-redshift-re-invented)
* [2012 re:Invent Day 1 Keynote: Andy Jassy](https://www.youtube.com/watch?v=8FJ5DBLSFe4&t=3170s)
  * 伝統的なデータウェアハウスは高すぎて、複雑すぎる。
    * ライセンスコスト、ハードウェアコスト
    * ガートナーの調査によるとデータウェアハウス1台に対して平均3-4人のDBAが雇用されている
  * 顧客満足度が低い
    * 大企業にとっては高すぎる、スケールが難しい
    * 中小企業にとっては高すぎて買えない
  * AWS 流のやり方でデータウェアハウスを提供したらどうなるか？
    * プロビジョニングが簡単で、スケールしやすい
    * 事前コストがなく、使った分だけ課金
    * 高パフォーマンス、低コスト
    * 人気のツールのサポートに対してオープンで柔軟
  * Redshift の導入
    * ペタバイト級のデータを簡単に迅速に分析する
    * 伝統的なデータウェアハウスのコストの1/10 
    * デプロイと管理の自動化
    * 人気の BI ツールに対応
  * MPP アーキテクチャ、コラム型ストレージで高いクエリパフォーマンス
    * 構成の選択肢
      * 16 TB ローカルディスクと 128 GB RAM
      * 2 TB ローカルディスクと 16 GB RAM
    * 最大100ノード、1.6 Pb
    * データをコラム型フォーマットに格納することで、従来より10倍、効率的・高速クエリ
    * 標準 SQL と JDBC/ODBC
  * 内部のテスト結果
    * Amazon、オンプレの伝統的なデータウェアハウス
      * 32 ノード、4.2 TB RAM、1.6 PB ディクス
      * 数百万ドル
