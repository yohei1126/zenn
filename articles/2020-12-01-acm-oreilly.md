12 月 に O'reilly Learning Platform の Subscription 更新期限が迫っていたので、噂に聞いていた ACM の会員になり、格安で O'reilly Learning Platform を利用するという TIPS をやってみました。

# O'reilly Learning Platform とは

ソフトウェアエンジニア界隈ではおなじみ。有名な技術書の老舗出版社です。最近はカンファレンスの主催もやっているようです。

以前は個別の電子書籍の販売もやっていたようですが、最近はsubscription方式で書籍・カンファレンス動画・トレーニング動画を利用し放題のサービスに特化しているようです。

https://www.oreilly.com/

このサービス、499 USD/年もします。個別の本を買うよりは読み放題の方が良いと思い、高いなと思いながら、個人プランを購入しました。

# ACM 会員になるとO'reilly learning platform が無料で利用できる

一方で、実は、ACM（アメリカの計算機学会）に加入すると、会員特典として O'reilly learning platform も無料で利用できます。（ACM会員費は別途発生）

* O'reilly Learning Platformに直接加入すると、サービス利用費が 499 USD / year もします。
* 一方で、ACM 会員特典の場合は、ACM 会員費を90ドル払うと、O'reilly Learning Platformを追加必要なしで利用できます。

# 利用手順

以下は実際にACMに加入して、O'reilly Learning Platform にアクセスするまでの手順です。

1. ACMの加入ページを開く https://www.acm.org/membership/join
2. "ACM Professional Membership" を選び、オプションでは "Professional Membership -- Yearly Rate: $ 99 (USD)" を選びます。もしACM自身のディジタルライブラリを利用したい場合は、"ACM Professional Membership PLUS ACM Digital Library -- Yearly Rate: $ 198 (USD)" を選んでください。
3. 決済が完了したら、ACMのLearning Centerのページを開き、右上の"O'reilly"をクリックすると、O'reilly Learning Platformにアクセスできます。
4. ログインでは、ユーザ名としてACMアカウントのメールアドレス、パスワードはACMアカウントのパスワードを入力します。

以上で利用できます。
