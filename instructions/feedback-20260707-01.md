## 読者が疑問に思いそうな点

### A. Bridge Keys と Graph Contract の関係

第1部 §6 では **Bridge Keys / フェデレーション契約** のみ。第2部では **Graph Contract** が登場。Mermaid では両方が Tech SSOT に並び、同義に見える。

**疑問:** 「Bridge Keys は Graph Contract の一部？別物？」

**推奨:** §2 の message か §3 冒頭に1文追加。

> Graph Contract はフェデレーション契約全体の機械可読な定義であり、Bridge Keys はその Identity Bindings に相当する。

### B. 「正規コンポーネントレジストリ」の位置づけ（第2部 §2.3）

§2.3 で **各グラフとは別層のマスター** が必要と書かれているが、§1.3 の二層図（Tech SSOT / 組織スライス / 横断ランタイム）には含まれていない。

**疑問:** 「4つ目のデータストア？誰が所有？Bridge Keys は誰が発行？」

**推奨:** 1段落で所有と責務を明示（例: 全社 MDM / 部品マスタが `Component.id` を正とする。各ドメイングラフは参照のみ）。第3部で `bom.duckdb` として実装するなら「第3部で具体化」と書いてもよい。

### C. `Supplier.id` はローカルなのに、分析はサプライヤー起点（第2部 §2.2 vs §4.2）

§2.2 では `Supplier.id` は調達ドメイン内に閉じる。§4.2 のシーケンスはサプライヤー影響から始まる。

**疑問:** 「他ドメインは Supplier を直接触れないのに、横断分析はどうサプライヤーから始める？」

**推奨:** §4.2 の前か §2.2 に1文。

> サプライヤー起点の問いも、**調達ドメインの決定論的ツール内** で `Supplier.id` → `Component.id` まで解決し、以降は Bridge Keys のみを他ドメインへ渡す。

### D. シーズン1の仮想グラフとの関係

第1部概要ではシーズン1（仮想グラフ）に触れるが、**「DWH 上の仮想グラフでは足りないのか？」** への答えがない。

**推奨:** 第1部 §1 か §4 に短い対比。

> 仮想グラフは **単一 DWH 上の論理グラフ** に向く。本シリーズは **組織別所有・書き込み権限が分かれた複数ストア** を前提とする——前提が異なる。

（第3部で DWH 接続を書くなら「ストレージは差し替え可能」と第2部末尾で触れてもよい。）

### E. `INPUT_OF` と第1部のパス図の不一致

第2部 §2.4 に `INPUT_OF`（Component → Process）がある。第1部 §3.1 と第2部 §4.2 の例は **`PRODUCED_BY`（Product → Process）** のみ。

**疑問:** 「工程への部品投入はどのエッジで辿る？」

**推奨:** 影響分析の **代表パスは Product 経由** と明記するか、`INPUT_OF` を「詳細分析用の補助エッジ」と注釈。

### F. Quality Gates / SLA Skew（第2部 §3.1 ④）

4要素目として定義されているが、**許容する鮮度差の例** がない。

**疑問:** 「EBOM が1週間古くても Sourcing は今日——それでも結合してよい？」

**推奨:** 1例（例: 影響分析は Sourcing/EBOM を T+0、Routing は T-1 まで許容、など）。

### G. Agent Skill の位置づけ（第2部）

シーズン1第3部の **Agent Skill** は、第2部では「名前付きクエリカタログ」に吸収された印象。

**疑問:** 「Skill は設計に登場しないのか？」

**推奨:** §4 か §3 に1文。Graph Contract / クエリカタログを **Agent Skill として LLM に提示する**（実装は第3部）——程度で十分。

### H. 第1部 §1.1 末尾がやや解を先出し

§1.1 最後で「AIエージェントの推論とクエリ連携によって論理的に結合」と書いており、§6 とも重なる。

**推奨:** §6 と表現を揃える（「次回設計編で扱う方向性」）。

### I. 第2部 §1.1 の「シーズン1および第1部」

物理統合の破綻は主に **第1部 §4** の話。シーズン1全体を指すと、第1・2部（What/Why）読者にはややズレる。

**推奨:** 「[第1部](...) で解説したとおり」に限定。
